# ml-dl-from-scratch

This repository contains my journey from **Python** to **Machine Learning** and **Deep Learning**, implementing concepts and models from scratch. It includes notebooks, examples, and small scripts used for learning and experimentation.

## Repository purpose ✅
- Learn and demonstrate core ML/DL concepts from first principles.
- Keep concise, well-explained notebooks and scripts for reference and practice.

## Structure 
- Notebooks: EDA, Feature Engineering, Models, Advanced topics
- Scripts: utilities and reproducible experiments
- Data: small CSVs used by notebooks

## Getting Started 🔧
1. Create a virtual environment:
   ```bash
   python -m venv venv
   ```
2. Activate the venv (Windows):
   ```powershell
   .\venv\Scripts\activate
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Open and run notebooks with Jupyter or VS Code.

## What "from scratch" means 🔍
- This repository begins at **core Python fundamentals** (data structures, OOP, functional programming, packaging) and progresses to data handling, EDA, feature engineering, and **implementing ML/DL algorithms by hand** (where practical).
- It also includes practical examples of **serving and deploying models** using small web apps and APIs — e.g., **Flask** apps, **Streamlit** UIs, and simple REST endpoints to demonstrate how to expose models for use.
- Standard tools and libraries (NumPy, Pandas, Matplotlib, Seaborn) are used where appropriate, but emphasis is on understanding the underlying algorithms and code.

## Notable folders & files 📁
- `Data Analysis/`, `EDA/` — exploratory data analysis notebooks and datasets
- `Feature Engineering/` — notebooks for handling missing data, encoding, scaling, SMOTE, outlier handling
- `Flask/` — example Flask app and templates for serving models
- `Streamlit/` — example Streamlit apps to interact with models
- `REST/` — small REST API examples and templates
- `package/` — a simple Python package and utilities
- `Multi Threading and processing/`, `Logging/` — practical examples used in larger pipelines
- `README.md`, `requirements.txt` — start here for setup and dependencies
